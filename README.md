# Gia-Kh-nh_-Study-Quest

Study Quest là ứng dụng lập kế hoạch học tập theo hình thức game, viết bằng HTML, CSS và JavaScript thuần.

## Tính năng

- Tạo nhiệm vụ với mục tiêu, môn học, thời lượng và hạn hoàn thành.
- Theo dõi nhiệm vụ đang làm, đã hoàn thành và tiến độ trong ngày.
- Nhận XP, lên cấp và dùng đồng hồ Pomodoro.
- Tự lưu kế hoạch trên trình duyệt bằng `localStorage`.

## Sử dụng

Mở `index.html` bằng trình duyệt. Không cần cài đặt thêm.
